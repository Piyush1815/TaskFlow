# TaskFlow – Kanban Board

TaskFlow is a simple, responsive Kanban board built using HTML and CSS. It helps organize tasks into three stages: To Do, In Progress, and Done.

## Features

- Three-column Kanban board layout
- Sample task cards
- High, Medium, and Low priority labels
- Task due dates
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox

## Project Structure

```text
TaskFlow/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
